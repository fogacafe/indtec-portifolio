# Indtec Portfolio

Personal engineering portfolio focused on software architecture, distributed systems, cloud and real-world technical challenges.

## Direction

This repository is intentionally built in small, reviewable iterations. The portfolio itself should remain simple: no backend unless a real requirement appears, no architecture added only for demonstration, and no skill percentages.

The visual language is inspired by modern product design and aerospace engineering interfaces: minimal, technical and content-first.

## Planned stack

- React
- TypeScript
- Vite

More tooling will only be introduced when it solves a concrete problem.
